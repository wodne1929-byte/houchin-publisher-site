개인정보처리방침

호우친 발행판(HouchinPublisher, 이하 "발행판")은 호남우파친구들(호우친, 이하 "운영자")이 자체 운영하는 내부 게시 도구입니다. 이 방침은 발행판이 Google(YouTube) 계정 접근 권한과 그로부터 받은 정보를 어떻게 다루는지 설명합니다.

1. YouTube API 서비스 사용

발행판은 YouTube API 서비스를 사용합니다. 발행판을 사용하면 YouTube 서비스 약관에 동의하는 것이 됩니다. Google이 정보를 다루는 방식은 Google 개인정보처리방침을 따릅니다.

2. 이용 대상

발행판은 운영자가 관리하는 호우친 공식 계정에만 사용합니다. 일반 이용자에게 제공하지 않으며, 회원 가입 기능이 없습니다. 발행판 화면은 운영자 기기에서만 열립니다.

3. 받는 권한과 읽는 정보

운영자가 Google 계정 승인(OAuth)을 거쳐 호우친 공식 유튜브 채널에 대한 다음 권한만 받습니다.

  • YouTube 동영상 업로드(youtube.upload): 운영자가 만든 영상과 제목·설명을 호우친 채널에 올리기
  • YouTube 계정 보기(youtube.readonly): 올바른 채널에 연결됐는지 확인하고, 호우친 채널 영상의 제목·공개 상태·길이와 통계(조회수, 좋아요 수, 댓글 수, 평균 시청 시간·평균 시청 비율)를 읽기
  • YouTube 계정 관리(youtube): 발행판으로 올린 호우친 영상의 공개 범위를 운영자가 확인한 뒤 '일부 공개'에서 '공개'로 바꾸기. 다른 설정이나 다른 영상은 바꾸지 않습니다.

다른 사람의 개인정보(시청자 정보, 연락처, 시청 기록, 댓글 내용 등)는 수집하지 않습니다.

4. 사용 목적

받은 권한과 정보는 (1) 호우친 채널에 영상 올리고 공개 범위 바꾸기, (2) 호우친 내부의 주간 성과 정리(어떤 영상이 반응이 좋았는지 보고 다음 기획에 반영)에만 사용합니다. 광고, 프로필 작성, 판매 등 다른 목적에는 사용하지 않습니다.

5. 보관 기간과 제3자 제공

  • 접근 토큰: 운영자의 컴퓨터에만 저장하며, 승인이 유지되는 동안만 보관합니다.
  • 채널 통계: 운영자의 컴퓨터와 운영자 내부 기록에 주간 성과 자료로 보관하며, 매주 다시 읽어 갱신합니다. 승인이 유지되는지 30일마다 확인합니다.
  • 영상 제목 등 그 밖의 정보: 30일이 지나면 지우거나 새로 읽어 갱신합니다.
  • 제3자에게 제공하거나 판매하지 않습니다. 발행판의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

6. 쿠키

발행판은 운영자의 로그인 상태를 유지하기 위해 운영자 브라우저에 쿠키 하나를 저장합니다. 이 공개 안내 페이지는 쿠키를 쓰지 않습니다.

7. 권한 철회와 삭제

Google 보안 설정 페이지(Google 계정 → 보안 → 서드파티 앱 및 서비스)에서 언제든 발행판의 접근 권한을 해제할 수 있습니다. 권한이 해제되면 발행판은 더 이상 채널에 접근하지 않으며, 저장해 둔 YouTube 정보는 7일 안에 지웁니다. 삭제 요청이나 개인정보 문의는 아래 연락처로 보내 주십시오.

Privacy Policy (English)

HouchinPublisher ("the tool") is an internal publishing tool operated by Honam Right Friends (Houchin, "the operator"). It is used only for Houchin's own official accounts. It has no public sign-up, and its dashboard is reachable only from the operator's devices.

YouTube API Services. The tool uses YouTube API Services. By using the tool, you agree to be bound by the YouTube Terms of Service. See also the Google Privacy Policy.

What we access. Through Google OAuth the tool requests only these permissions: youtube.upload (to upload Houchin's own videos, with titles and descriptions, to Houchin's YouTube channel), youtube (only to change the privacy status of videos uploaded by the tool from unlisted to public after the operator has checked them) and youtube.readonly (to confirm the connected channel and to read Houchin's own videos' titles, privacy status, duration and statistics: views, likes, comment counts, average view duration and average view percentage). No data about other people (viewers, contacts, watch history, comment text) is collected.

How we use it. Only to (1) upload Houchin's videos and set their privacy status and (2) prepare Houchin's internal weekly performance notes. Not used for advertising, profiling or sale.

Storage and sharing. Access tokens are stored only on the operator's computer while authorization is in effect. Channel statistics are stored on the operator's computer and internal notes, refreshed weekly, and authorization is re-checked at least every 30 days. Other API data such as video titles is deleted or refreshed after 30 days. Data is not sold or shared with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Cookies. The tool stores one cookie in the operator's browser to keep the operator signed in. This public information page uses no cookies.

Revocation and deletion. Access can be revoked at any time on the Google security settings page. After revocation the tool stops accessing the channel and deletes stored YouTube data within 7 days. For deletion requests or privacy questions, contact official@houchin123.com.
