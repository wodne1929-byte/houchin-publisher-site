개인정보처리방침

호우친 발행판(HouchinPublisher, 이하 "발행판")은 호남우파친구들(호우친, 이하 "운영자")이 자체 운영하는 내부 게시 도구입니다. 이 방침은 발행판이 Google(YouTube) 계정 접근 권한을 어떻게 다루는지 설명합니다.

1. 이용 대상

발행판은 운영자가 관리하는 호우친 공식 계정에만 사용합니다. 일반 이용자에게 제공하지 않으며, 회원 가입·로그인 기능이 없습니다.

2. 받는 권한과 정보

운영자가 Google 계정 승인(OAuth)을 거쳐 호우친 공식 유튜브 채널에 대한 다음 권한만 받습니다.

  • YouTube 동영상 업로드(youtube.upload): 운영자가 만든 영상을 호우친 채널에 올리기
  • YouTube 계정 보기(youtube.readonly): 올바른 채널에 연결됐는지 확인하기

이 밖의 개인정보(다른 사람의 정보, 연락처, 시청 기록 등)는 수집하지 않습니다.

3. 사용 목적

받은 권한은 위 두 가지 목적에만 사용합니다. 광고, 분석, 프로필 작성, 판매 등 다른 목적에는 사용하지 않습니다.

4. 보관과 제3자 제공

접근 토큰은 운영자의 컴퓨터에만 저장하며 제3자에게 제공하거나 판매하지 않습니다. 발행판의 Google 사용자 데이터 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

5. 권한 철회

Google 계정 → 보안 → 서드파티 앱 및 서비스에서 언제든 발행판의 접근 권한을 해제할 수 있습니다. 해제하면 발행판은 더 이상 채널에 접근할 수 없습니다.

Privacy Policy (English summary)

HouchinPublisher is an internal tool operated by Honam Right Friends (Houchin) and used only for Houchin's own official accounts. Through Google OAuth it requests only youtube.upload (to upload Houchin's own videos to Houchin's YouTube channel) and youtube.readonly (to confirm the connected channel). No other personal data is collected. Data is used only for these purposes, is not used for advertising or analytics, is not sold or shared with third parties, and access tokens are stored only on the operator's computer. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time in Google Account → Security → Third-party apps & services. Contact: official@houchin123.com. Effective: October 5, 2026.
